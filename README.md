Data Structures: Chapter-wise Questions, Exercises and MCQs

This repository holds the end-of-chapter practice material for the textbook Data Structures by Dr. K. V. Sambasiva Rao, Director, R&D Cell, Department of Computer Science and Engineering, Dr. RVR  NRI Institute of Technology (Deemed to be University), Agiripalli, Vijayawada, Andhra Pradesh, India.

To keep the printed book compact, the technical/interview questions, programming exercises, multiple choice questions (MCQs) and answer keys of all 12 chapters are published here instead of in the book. Every chapter has one PDF for reading and printing, and one Markdown file with the same content for viewing directly on GitHub.

What each file contains

Each chapter file has four parts: the technical/interview questions, the programming exercises (Chapter 1 has a section called "Exercises" instead), the multiple choice questions with their options, and the answer key as a table. Question numbers are the same as in the book.

Answer keys and corrections

The answer keys here are the corrected ones. They replace the keys printed in the first edition wherever the two differ: Chapter 3 Q12, Chapter 5 Q1 and Q17, Chapter 6 Q31 and Q32, Chapter 9 Q3, Q5 and Q6, Chapter 10 Q14, and Chapter 12 Q1. Typing slips in the original MCQ text (for example, option labels in Chapter 9 and a few symbols in Chapter 1) have also been fixed.

How to use

Students can read a chapter's PDF alongside the textbook and attempt the questions before checking the answer key at the end of the same file. Teachers can print the PDFs directly or copy questions from the Markdown files into assignments and tests.

Feedback

If you find a mistake in a question, option or answer key, please open an issue in this repository with the chapter number, the question number and the correction you suggest.
